## Issues & Fixes

- 三角形がライト方向に対して明暗がつくようになるところ、暗いままだった。

　　原因：法線Nとライト方向が逆向き（裏面扱い）になっていた。

　　　　　Lambertの法線とライト方向の内積の計算で、負の値になりsaturate関数のクランプで0になったため拡散反射が消えていた。

　　解決方法：頂点の法線を（0, 0, 1）から（0, 0, -1）に変更し、カメラから見る表面を表側の向きに合わせた。

　　　　　　　今回は三角形が原点の位置にあり、カメラはZ＝-5の位置のため、カメラから見える表面は手前側なので表面の法線は-Zが自然。

　　　　　　　そのため、頂点法線を（0, 0, 1）にしているとカメラから見た面は裏面扱いになり、暗く映っていた。
